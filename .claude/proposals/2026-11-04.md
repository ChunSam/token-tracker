## hook 후보

### 턴 끝 보고가 한국어가 아니면 다시 쓰게 한다 (Stop, 프로젝트)

- **근거:** 규칙 후보 1과 같다. 규칙이 있는데도 87번 어겼으니, 강제할 수단도 같이 본다.
- **한계:** 턴 끝에서만 돈다. 이 구간의 실제 세션에 대 보니 걸리는 것은 64턴 중 2턴이고, 87건 대부분인 턴 중간 진행 보고는 못 잡는다. 그래서 우선순위는 규칙 후보 1보다 낮다. 규칙으로 고쳐지지 않을 때 넣는다.
- **스코프:** 언어 규칙이 이 저장소 CLAUDE.md에만 있다. 그래서 기본은 프로젝트 `.claude/settings.json`이다. 다른 저장소에서도 같은 일이 있는지는 보지 않았다.
- **기존 hook과의 관계:** Stop에는 `cc-status`(iTerm 상태 표시)만 있어서 겹치지 않는다.
- **검증:** 합성 트랜스크립트로 확인했다. 영어 보고는 exit 2로 막고, 한국어 보고, 80자 미만 영어, `stop_hook_active`는 통과시킨다. Stop 시점에 마지막 메시지가 이미 트랜스크립트에 적혀 있는지는 설치할 때 확인해야 한다.

```bash
#!/bin/bash
# 마지막 보고가 한국어가 아니면 다시 쓰게 한다 (Stop).
in=$(cat)
[ "$(jq -r '.stop_hook_active // false' <<<"$in")" = "true" ] && exit 0
t=$(jq -r '.transcript_path // empty' <<<"$in"); [ -f "$t" ] || exit 0
lang=$(python3 - "$t" <<'PY'
import json, re, sys
last = ""
for line in open(sys.argv[1], encoding="utf-8", errors="ignore"):
    try: o = json.loads(line)
    except Exception: continue
    if o.get("type") != "assistant": continue
    txt = "".join(c.get("text", "") for c in o.get("message", {}).get("content", []) if isinstance(c, dict) and c.get("type") == "text")
    if txt.strip(): last = txt
print("en" if len(last) >= 80 and not re.search("[가-힣]", last) else "ok")
PY
) || exit 0
[ "$lang" = "en" ] || exit 0
echo "대화는 한국어로 한다(CLAUDE.md). 방금 보고를 한국어로 다시 써라." >&2
exit 2
```
